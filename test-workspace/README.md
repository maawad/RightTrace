# RightTrace Test Workspace

This directory contains sample trace files for testing the RightTrace extension.

## Files

- `trace-small.json`: Minimal synthetic trace event.
- `trace-large.json`: Slightly larger synthetic trace with multiple events.

## Usage

1. Open this folder (`test-workspace`) in VS Code / Cursor as a workspace.
2. Right-click one of the JSON files in the Explorer.
3. Choose **RightTrace: Open in Perfetto UI**.
4. A new editor panel should appear with the Perfetto UI loaded in an in-editor browser.
